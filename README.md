# The Filmkaar Weddings — GitHub Pages

## Files
- `index.html` — homepage
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `images/` — replace the placeholder image files with your own photographs

## Add your images
Put these files inside `images/`:
- hero.jpg
- wedding-1.jpg
- wedding-2.jpg
- wedding-3.jpg
- wedding-4.jpg
- wedding-5.jpg
- wedding-6.jpg
- about.jpg

The filenames must match exactly.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `images` folder.
3. Go to Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/root`, then Save.
6. GitHub will give you a public website URL.

## Custom domain
In GitHub Pages settings, add your domain under Custom domain, then update your domain DNS records as instructed by GitHub.
